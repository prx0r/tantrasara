## 1. The work (fixed — same as every text on this machine)

Take a long teaching (audio + its text) and produce the clearest possible
path through it — not a shorter playlist, but an *argument*: six built
sections that explain the thing so a first-time listener gets it, at four
depths. First build here is Abhinavagupta's *Tantrasara*.

## 2. The gospel (fixed — never reordered)

Every unit of content is exactly three layers, in this order:

    TEXT VERBATIM → PLAIN ENGLISH → AUDIO (archive voice)

Nothing else exists. No summaries, no bridges, no composed prose — not in
files, not in chat. The archive voice reads AND explains; Fish speaks
key-mappings only; the owner's hand writes intros and questions.

## 3. The spine — section questions (SHARPENED 2026-10-29; owner ratifies)

Passes the analayo FORMULA (standalone+precise · the cut · content-fit ·
plain ≤9) + the oral test (read Q then A aloud; leap = rewrite the Q).

1. **What is my own nature?** — svabhava: self-shining light, bliss, the
   heart as universal bliss (Ch 1).
2. **Why don't I see it right now?** — twofold ignorance; grace (saktipata),
   not merit, decides (Ch 1, 11).
3. **What keeps me bound?** — the veils: time, knowledge, wanting, effort;
   mala as the Lord's will to conceal; delight in the limited (Ch 1, 4, 8).
4. **How do I see this?** — the four upayas as four ways of SEEING,
   graded by capacity, not chosen by you: one hearing / reflection /
   true thought / breath-body-practice (Ch 2–5; lineage crossing Ch 17).
   (Owner decree 2026-10-29, superseding "Which way in is mine?"; the
   means-section is really the question of perception — knowledge is
   what liberates.)
5. **How do I practice?** — breath is time; the bath, offering, mantra
   are inner absorption; daily and occasional rite (Ch 6, 12–14, 18, 20).
6. **What remains after death?** — net-rescue from any realm, festival-
   death of the knower, jagadananda, Bhairava identity, glance-initiation
   (Ch 15–19, 22).

Edge chain: light → unseen? → what holds it → which door → do it → then
what. Alternates kept in essay0_DRAFT (folding 5+6, Q5 as "What do I
actually do?", Q1 as "What is the goal?"). Content-fit: every question
answered aloud by its chapters (grasp note §2); Q5 carries 47 spans —
structural for a manual.

## 4. Essay 0 — the gold dust (OWNER PICKS from candidates)

Per section: the compressed answer that still explains fully. Built FIRST,
as micro-sessions (question + answer written and read together). Recurs 4×
(seed, core, gold, pool) with a layer-bell at each re-entry.

## 5. The ritual (fixed shape; voices cast per text)

motto-bell → guide asks the question → recollect pause → guide gives the
plain-English response → breath → essay-0 verbatim on screen + archive
pointer → beats → zoom-bell. Two bells only. Nothing wedged between
question and answer.

## 6. Roles (fixed shape; cast per text)

- **Owner** — picks (questions, essay-0 candidates, mixes, ears).
- **Archive voice** — reads + explains; owns all sacred-language-aloud.
- **Guide (TTS)** — key-mappings + plain lines only (cast per text;
  reference: kid asks, old man answers in analayo-nibbana).
- **Machine** — pipeline, gates, swaps, notes. Never generates content-voice.

## 7. What gates are for (fixed)

Gates guard the FLOOR: provenance (every sacred word exists somewhere,
exact), stale paths, slop canaries, memory-claims. They never encode
taste. A passing gate is permission to have an opinion, not a verdict.
